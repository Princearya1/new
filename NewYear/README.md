Happy New Year Site for Pallavi (Pallu)

Quick start

- Open [index.html](index.html) in your browser.
- The slideshow now automatically loads images from the `pic` folder (pic1.jpeg ... pic8.jpeg). No upload needed.
- Click "Play Music" to load and play the provided YouTube song. Music requires a user interaction to start on most browsers.
 - Background music currently set to: https://www.youtube.com/watch?v=BIqC-6pkT0o
- Click "Celebrate" to trigger confetti.

Customization

- Edit `index.html` to change messages and names.
- Replace or add photos using the file picker (or put images in the `pic` folder and use the file picker to select them).
- To change the music, update the YouTube video ID inside `script.js` where the player is created.

Notes

- Autoplay policies on some browsers may prevent audio from starting without user interaction. Use the "Play Music" button to start playback.
- The slideshow uses local file URLs created from the browser file input for privacy; files are not uploaded anywhere.
